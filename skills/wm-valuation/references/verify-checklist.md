# Verify 清单（写后再用；硬门禁另见 ci 脚本）

## G1 硬伤（出现即失败）

### 裁决词禁区

- 假便宜 / 假贵 / 击球区 / 安全边际 / 类债公允 / 类债终局
- 分位偏高/偏低、估值偏贵/偏高/偏低、明显偏*
- 复合裁决词：公允偏低 / 公允偏高 / 算是便宜 / 略贵
- 程度副词：真便宜 / 明显偏低 / 明显偏高
- 猎手词：严重低估 / 泡沫 / 绝对底部 / 锁定真便宜

### 诊断专名门

- 无 `flags` 对应旗标却点名：分母扩张 / 分母收缩 / 假便宜 / 假贵 / 席勒分叉 / 周期顶部 / PB-ROE顶部错配
- 无 flag 时禁否定/教学句打开该话题（并非/别碰/典型形态）
- 席勒分叉：无 `flags.shiller_fork=true` 却展开论述

### 周期顶部持续性

- `is_cycle_top=true` 或 `has_pb_roe_top_mismatch=true` 时，未走持续性三问（供给刚性/PB隐含持续期/非价格收益）而直接落「数据不足」或回避结论 → G1
- 顶部信号出现时，盈利收益率作绝对锚判「偏低」（峰值 EPS 抬高=假便宜口径）→ G1

### 金融文泄漏（金融 variant）

- 净现比、八型、奶牛型、蝙蝠型、老母鸡型
- EV / 企业价值倍数 / PEG / 席勒市盈率 / DCF / FCF / 净现金 / 净债务
- 「破净=资产被低估」「重资产」

### 数据准确

- 正文关键数字在 `data.result` 无出处
- TTM 与近3年年化假对齐（误导对照）
- 杜撰分部占比（JSON 无 `top_share` 却写了精确占比）

## 结构（软）

- 有标题、商业模式、30秒、核心观点 3 条（头区散文）
- **核心观点#2 必含且仅含一个裁决四枚举整词**（工业：公允/偏低/偏高/数据不足；金融：折价/合理/溢价/数据不足）
- **估值小表**（主）：`指标|数值|五年分位`；**对照表**（辅）：仅本章 ≥2 行双侧同口径时出
- **禁止**「本公司指标」小节/两列表；**禁止**旧表头「对照/分位」；**禁止**用 `—` 凑行业列
- 表内**无**解读散文；**无**现金流类型/`kind_desc` 行
- 解读长度合宜；数字对账；无依据 `≈` → 重写
- 套话错配 → 重写；金融文若出现 EV/FCF → 重写

## 字数

不是 G1。软区间约 700～1400 汉字。总原则：专业、买方、准确、简洁、易懂。
