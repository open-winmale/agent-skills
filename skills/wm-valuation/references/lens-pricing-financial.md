# 透镜：pricing_financial（金融定价匹配）

金融高杠杆为常态；勿用实业「杠杆过高=差」一刀切。
用于**解读段**。无 EV/FCF/净现金/PEG/Schiller（已剥离）；主判据 **PB × ROE 持续性**。

第一性原理：长期看金融盈利能力（ROE）能否持续（水平 × 稳定性 × 轨迹）；价格侧看 PB 与可辩护持续 ROE 是否匹配。

裁决枚举：**折价 / 合理 / 溢价 / 数据不足**。

## 银行（bank）

- ROE 与息差、中收、拨备相关；负债主体是存款。
- 买方提示：破净（PB<1）为常态非低估；上行看息差/资产质量/中收回写 ROE；分位只做卫生。
- 忌：「破净=资产被低估」；白酒式「品牌壁垒」。

## 券商（broker）

- 收入结构看经纪/自营/投行；PB 分位反映行情持续性预期。
- 买方提示：低分位+利润正增速 → 非低估；高分位+利润负增速 → 非高估。不写死 PB 合理区间表。
- 忌：「重资产」。

## 保险（insurer）

- 利差损与新业务价值是主矛盾轴；内含价值口径数据缺位。
- 买方提示：用 ROE 稳定性作内含价值质量代理；凡涉及 PB，后缀「内含价值专项数据缺位，结论为参考」；禁把低分位直接写成低估。
- 忌：把 ROE 波动直接写成经营改善/恶化裁决。

## 其他金融（other）

- 只用 JSON 出现的事实；缺则删行。
- 忌：硬套 bank/broker/insurer 套话。

## 通用纪律

- 主 PB 绑定 `as_of` 的 `pb_daily`；`pb_qe` 仅季末趋势对照
- PE 仅盈利收益率参考，挂「利润分母效应，非定价信号」
- 下行保护仅来自净资产/PB 折价，禁工业现金清算话术
- `pb_daily` ≤0 或 nil → 「PB 数据缺失，金融估值无意义」并终止
- `roe_avgipo` nil 或上市年限 <3 → 标注稳定性参考不足

阈值仅作柔锚：仍以 JSON 为准，勿编造监管数值。
