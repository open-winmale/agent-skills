# 术语与口径 SSOT（全卡通用）

## 比率与单位格式（严防小数漏乘 100）

- **×100 加 %**：ROE / 净利率 / 资产负债率 / 股息率 / 分红率 / 分位（pct5y）/ 同比（yoy）—— 均为 0~1 原始小数，输出**必须 ×100 后加 %**（0.4329 → 43.29%）。
- **不加 %（例外）**：
  - PE / PB / PR / EV/EBITDA → 保留 2 位小数，无单位（20.04）
  - PEG → 保留 2 位小数，无单位
  - 盈利收益率 / FCF收益率 → 保留 2 位小数加 %（0.0545 → 5.45%）
  - 金额 → 亿元（HK 标报表币种）
- **百分点 pp ≠ %**：率差写「X 个百分点」或「Xpp」，禁止把率差当比率再 ×100。

## 分红率 vs 股息率（禁止互换）

- **分红率**（payout）= 现金分红 ÷ 净利润。字段 `payout`（`$BONUS_TTM_RATE`）。量级常 30%~70%。带 %。
- **股息率**（dividend yield）= 现金分红 ÷ 市值。字段 `dividend_yield`（`$BONUS_RATE_TTM_LAST`）。量级常 1%~6%。带 %。
- 禁止把 3% 量级股息率标为「分红率」；禁止把 50%+ payout 标为「股息率」。

## Period 对用户展示

- 日频字段（`pe_daily`/`as_of`）→ 「截至 YYYY-MM-DD（日频）」
- 季末字段（`pe_qe`）→ 「截至 YYYY:QN（季末）」
- FCF / 席勒 → 「年报 Q4 口径」/「近 10/5 年均值」
- 行业字段（`industry.*`）→ 标注「整体法 TTM」或「近3/10年均值」，**不是**本公司报告期 TTM 同比
- **禁模糊时间词**：最新/当前/最近一期/目前 → 一律用 period/as_of 具体值

## 术语速查（白话）

| 词 | 白话 |
|----|------|
| ROE | 股东回报（一块净资产赚多少） |
| PE | 市盈率（股价是盈利的几倍） |
| PB | 市净率（股价是净资产的几倍） |
| PR | 市赚率（PE ÷ ROE，PE 相对赚钱本事的贵贱） |
| PEG | PE ÷ 增速（成长股匹配参照） |
| 席勒 PE | 常态化市盈率（近 10/5 年净利均值 × PE 均值，周期股用） |
| EV/EBITDA | 企业价值倍数（剔资本结构，工业适用；金融禁） |
| 盈利收益率 | 1 ÷ PE（绝对锚之一，与无风险利率比） |
| FCF 收益率 | 自由现金流 ÷ 市值（绝对锚之一；金融禁） |
| 分母效应 | 利润分母变动导致分位失真（低分位≠低估） |
