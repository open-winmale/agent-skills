# 设计原则与要点（估值解读卡）

本卡 = Insight `valuation` / `valuation_financial` 的 **SkillHub 事实孪生**：XS 出可对账事实 + 诊断信号，Agent 按 Pack 写定价备忘录。只报匹配松紧，不做买卖点。

## 分层（硬）

| 层 | 负责 | 不负责 |
|----|------|--------|
| **XS / Data+Gate** | 取数、口径、金融剥离、HK 金融拦截、`methodology` / `enrich_plan` / `quality` / `flags` | 写定价备忘录正文 |
| **Pack / Narrative** | 透镜、指令、输出骨架、Verify | 改数字、编造对照、改 `enrich_plan` |

一次 `skills/run` 拿齐事实面；解读只在宿主 LLM 侧按 `enrich_plan.required_reads` 生成。

## 五原则（高于篇幅）

**专业 · 买方视角 · 准确 · 简洁 · 易懂**

冲突序：**准确 > 简洁 > 填满**；专业/买方 > 文采。

| 原则 | 落点 |
|------|------|
| 专业 | 买方口径；禁荐股/营销腔；分位与增速只报事实 |
| 买方 | 解读回答「价格是否匹配持续盈利能力」；只报松紧 |
| 准确 | 数字照抄 JSON；禁无依据 `≈`、禁心算派生、禁编造对照 |
| 简洁 | 每章解读 2～4 短句；缺字段不写；不为表而表 |
| 易懂 | 术语括注；表头语义清楚；禁内部字段名 |

## 裁决四枚举（核心约束）

| 卡 | 枚举 | 含义 |
|----|------|------|
| 工业 | **公允 / 偏低 / 偏高 / 数据不足** | 相对可辩护持续盈利能力的松紧 |
| 金融 | **折价 / 合理 / 溢价 / 数据不足** | PB 相对可持续 ROE 的松紧 |

- 松紧叙述用「匹配偏松/偏紧」
- **禁**复合词：公允偏低 / 公允偏高 / 算是便宜 / 略贵
- **禁**程度副词升级：明显偏低 / 明显偏高 / 真便宜
- **禁**猎手词：严重低估 / 泡沫 / 绝对底部 / 击球 / 击球区 / 锁定真便宜
- **禁**类债终局（有收割候选/增长减速 label 时尤禁）

## 诊断专名门（Verify 重点）

| 专名 | 何时可点名 |
|------|-----------|
| 分母扩张压分位 / 假便宜 | **仅** `flags.fake_cheap_risk=true` 时 |
| 分母收缩抬分位 / 假贵 | **仅** `flags.fake_expensive_risk=true` 时 |
| 席勒分叉 / 席勒分叉显著 | **仅** `flags.shiller_fork=true` 时 |
| 收割候选 | **仅** `flags.harvest_candidate=true` 时 |
| 周期顶部 | **仅** `flags.is_cycle_top=true` 时；强制走持续性三问 |
| PB-ROE顶部错配 | **仅** `flags.has_pb_roe_top_mismatch=true` 时；强制走持续性三问 |
| 无旗标 | 只写分位数字 + 利润/价格事实（用语限「利润分母效应」）+ ≠低估/≠高估；禁点名、禁「分母扩张」、禁否定/教学句 |

**周期顶部持续性三问**：`is_cycle_top`/`has_pb_roe_top_mismatch` 任一为 true 时，顶部的反面不是「贵」是「持续时间短」，须走三问（供给刚性/PB隐含持续期/非价格收益）而非默认回避/数据不足；详见 `instruction-cn-industrial.md`。

## 输出形态（估值小表为主 + 对照表为辅）

| 规则 | 说明 |
|------|------|
| 估值小表（主） | 有 PE/PB + 分位 → `指标 \| 数值 \| 五年分位` |
| 估值小表零表 | 凑不齐行（如亏损期只剩 PB、缺分位）→ 该章零表，数字写散文。**无表优于碎表** |
| 行业对照表（辅） | 本章 ≥2 行双侧同口径 → `指标 \| 本公司 \| 行业` |
| 零表 | 稀疏 / 港股缺行业 → 该章零表，数字写解读 |
| 禁碎表 | 禁「本公司指标」两列表、禁止 `—` 凑列 |
| 口径 | TTM 同比 ≠ 近3年年化；不一致勿强行对照 |
| 现金流类型 | **永不入表**；禁展开投资科目 |
| 估值 | 默认估值小表；第三章允许 `指标 \| 数值 \| 五年分位` |

稀疏/港股缺对照时，**无表优于碎表**。

## Gate 与卫生

- **CN 金融**：剥 FCF/席勒/商誉等结构损坏字段；换金融 instruction + lens；主判据切 PB × ROE
- **HK 金融**：请求层 `blocked`，只出 `blocked_message`
- **亏损期**（`is_loss`）：禁 PE/PEG 低估高估定性；透镜限 PB + EV/EBITDA；可谈净现金托底

## Agent 工作要点

1. 先 `run`，读 `methodology` / `enrich_plan` / `quality` / `flags`；`blocked` 则停
2. **禁止改** `enrich_plan`；Read 完 `required_reads`，勿读 `do_not_load`
3. 按 `output-skeleton` 起草；裁决四枚举整词；诊断专名门；数字对账；透镜禁行业套话串味
4. `verify-checklist` + G1=0；最多回退 2 次
5. 字数软区间约 700～1400 汉字；不承诺每次合格，但不合格可检测
6. 勿与 `wm-company-business` 混淆；勿默认调 `/v1/insight/report`
