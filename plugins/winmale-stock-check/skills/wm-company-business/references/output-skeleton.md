# 输出骨架（对照表-only + 散文）

## 五原则（高于篇幅）

| 原则 | 要求 |
|------|------|
| **专业** | 买方口径；禁荐股/营销腔；分位与增速只报事实 |
| **买方视角** | 解读回答「对仓位意味着什么事实」；定价只定位，匹配见估值卡 |
| **准确** | 表内只准照抄 JSON 数值与口径；禁无依据 `≈`、禁心算派生、禁编造对照 |
| **简洁** | 每章解读 2～4 短句（定价章 ≤2）；缺字段不写；不为表而表 |
| **易懂** | 术语首次括注；表头语义清楚；禁内部字段名 |

冲突：**准确 > 简洁 > 填满**；专业/买方 > 文采。

**表 = 双侧同口径可对账数字；其余 = 散文。** 禁止「维度｜数据｜解读」三列表；禁止「本公司指标」两列表。

## 表规则（硬）

| 何时 | 做什么 |
|------|--------|
| 本章有 **≥2 行**「本公司 + 行业」同口径数字 | 至多一张 `#### 与行业对照`，表头 `指标 \| 本公司 \| 行业` |
| 不足 2 行或无行业侧 | **该章零表**；数字写入解读段 |
| 估值 PE/PB + 五年分位 | **默认散文**；若用表，仅第三章允许一张 `指标 \| 数值 \| 五年分位`（可选） |

细则：

- **禁止**用 `—` 凑第三列；禁止混表；禁止旧表头「对照/分位」；禁止工程词「对比/独列」
- **行业列只放一个主数字**；「行业内分位」用括号短注 `(行业内分位 xx%)` 或放到解读句
- **口径不一致勿强行对照**（如本公司 TTM 同比 vs 行业近3年年化）：不同口径进散文并点明口径
- **`kind_desc` / 现金流类型永不入表** → 第二章解读用类型短名一句（如「老母鸡型」）；禁展开投资科目
- 金融：无净现比/八型；有对照则仍可出对照表

## 模板（有行业对照）

```markdown
**{name}** {symbol} · {industry_l1_tag} · {industry_l3_tag}

> **商业模式：** [1 句；禁定价裁决]

### 30秒读懂
> **30秒读懂：** [约 ≤60 字]

### 核心观点
1. …
2. …
3. …

### 一、生意基因

#### 与行业对照

| 指标 | 本公司 | 行业 |
|------|--------|------|
| ROE（TTM） | … | …（行业内分位 xx%） |
| 毛利率（TTM） | … | 近3年均值… |
| 净利率（TTM） | … | 近3年均值… |
| 股息率（TTM） | … | 近3年均值… |

[解读 2～4 短句：含第一大业务与占比、净现比/市值（有则）、对照含义。无对照数字不另建表。]

### 二、核心矛盾

#### 与行业对照

| 指标 | 本公司 | 行业 |
|------|--------|------|
| 营收近3年年化 | … | … |
| 净利近3年年化 | … | … |
| 资产负债率 | … | … |

[解读 2～4 短句：TTM 同比、有息负债（有则）、矛盾判断；现金流用类型短名一句，**不入表**]

### 三、定价位置

PE（TTM）…、五年分位…；PB…、五年分位…。只报位置事实；低分位≠低估；匹配见估值卡。

（可选小表替代上句：）

| 指标 | 数值 | 五年分位 |
|------|------|----------|
| PE（TTM） | … | … |
| PB | … | … |
```

## 模板（缺行业 / 稀疏：零表）

```markdown
### 一、生意基因

[散文：ROE/毛净利/业务占比/净现比/市值等有则写入；一句点明缺行业对照，勿编造。]

### 二、核心矛盾

[散文：TTM 同比、年化（仅本公司侧）、偿债、现金流短名。]

### 三、定价位置

[散文或可选估值小表；低分位≠低估；匹配见估值卡。]
```

头区仍散文。字数软区间约 **700～1400** 汉字。
