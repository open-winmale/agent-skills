# 输出骨架（估值小表为主 + 对照表为辅 + 散文）

## 五原则（高于篇幅）

| 原则 | 要求 |
|------|------|
| **专业** | 买方口径；禁荐股/营销腔；分位与增速只报事实 |
| **买方视角** | 解读回答「价格是否匹配持续盈利能力」；只报松紧，不做买卖点 |
| **准确** | 表内只准照抄 JSON 数值与口径；禁无依据 `≈`、禁心算派生、禁编造对照 |
| **简洁** | 每章解读 2～4 短句；缺字段不写；不为表而表 |
| **易懂** | 术语首次括注；表头语义清楚；禁内部字段名 |

冲突：**准确 > 简洁 > 填满**；专业/买方 > 文采。

## 裁决四枚举（核心观点#2 必含且仅含一个整词）

- 工业：**公允 / 偏低 / 偏高 / 数据不足**
- 金融：**折价 / 合理 / 溢价 / 数据不足**

禁复合词（公允偏低/算是便宜/略贵）；禁程度副词（明显偏低/真便宜）；松紧叙述用「匹配偏松/偏紧」。

## 表规则（硬）

| 何时 | 做什么 |
|------|--------|
| 有 PE/PB + 五年分位 | **估值小表**（主输出）：`指标 \| 数值 \| 五年分位` |
| 估值小表凑不齐行（如亏损期只剩 PB、或缺五年分位） | **该章零表**；数字写散文。无表优于碎表 |
| 本章有 **≥2 行**「本公司 + 行业」同口径数字 | 至多一张 `#### 与行业对照`，表头 `指标 \| 本公司 \| 行业` |
| 不足 2 行或无行业侧 | **该章零对照表**；数字写入估值小表或解读段 |

细则：

- **禁止**用 `—` 凑第三列；禁止混表；禁止旧表头「对照/分位」
- **行业列只放一个主数字**；「行业内分位」用括号短注 `(行业内分位 xx%)` 或解读句
- **口径不一致勿强行对照**（如本公司 TTM 同比 vs 行业近3年年化）：不同口径进散文并点明
- **`kind_desc` / 现金流类型永不入表** → 解读用类型短名一句；禁展开投资科目
- 金融：无 EV/FCF/净现金；主判据 PB；有行业 PB 对照则可出对照表

```markdown

### 30秒读懂
> **30秒读懂：** [≤45 字：盈利能力一句 + 公允|偏低|偏高|数据不足整词；截至 {as_of}]

### 📌 核心观点
1. **【盈利能力与持续性】** ROE / `roe_avgipo` + 轨迹 + 兑现。≤40 字。
2. **【价格匹配与绝对锚】** [四枚举整词] + 绝对锚（盈利收益率 / FCF 收益率 / 股息利差之一）+ 必要分位。
```
