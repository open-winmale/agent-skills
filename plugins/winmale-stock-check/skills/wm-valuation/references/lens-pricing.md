# 透镜：pricing（实业定价匹配）

【盈利能力持续性 × 价格匹配的行业透镜】
先看 JSON 中行业标签，匹配最接近模式；勿编造阈值表。
用于**解读段**（≤2～4 短句）；表内不写解读。

第一性原理：长期回报取决于盈利能力能否持续（水平 × 稳定性 × 轨迹，及向 FCF/分红的兑现）。倍数与分位是衍生描述。

## 1. 高毛利低周转型（白酒、奢侈品、创新药、软件/SaaS）

- 主方法：**PE + 席勒**（高净利率支撑高 ROE，PE 含量高）
- 买方提示：ROE 是否由净利率支撑、能否持续；分位是否被分母扩张压低（看 `flags.fake_cheap_risk`）
- 忌：把品牌壁垒套到未显示该模式特征的标的；类债终局

## 2. 低毛利高周转型（零售、白电、快消、餐饮）

- 主方法：**PE + ROE 稳定性**（周转是生命线）
- 买方提示：周转节奏对 ROE 的侵蚀；盈利收益率作绝对锚
- 忌：写「印钞机」类高毛利话术

## 3. 周期制造型（钢铁、煤炭、化工、航运、有色）

- 主方法：**席勒（常态化盈利）**；现期 PE 失真
- 买方提示：ROE 周期位置；席勒分叉（`flags.shiller_fork=true` 时一句）
- **顶部持续性三问**（`is_cycle_top`/`has_pb_roe_top_mismatch` 为 true 时强制）：顶部的反面不是「贵」是「持续时间短」——产能红线/牌照/资源壁垒可让顶部持续多年。①供给刚性决定顶部持续多久；②PB 分位隐含市场认为顶部还能持续几年；③量增/分红率/成本下移能否对冲价差回落（`cyclical_nonprice_facts`）。证据未闭合可观望，但顶部本身永不作为回避理由。
- 忌：线性外推顶部高 ROE；无数据背书的「价格顶部」；**把「顶部」当回避理由**（顶部的反面是持续时间短，不是贵）

## 4. 科技成长型（半导体、互联网、通信设备、新能源设备）

- 主方法：**PEG + 增速**（成长期看收入与毛利扩张）
- 买方提示：盈利收益率/FCF 收益率是否匹配；增长是否跟上（无对应 flag 时只写数字事实）
- 忌：空洞「赛道空间广阔」；高增叙事写成买入终局

## 5. 资源型（石油、矿产、养殖）

- 主方法：**席勒 + EV/EBITDA**
- 买方提示：盈利对价格敏感的事实（有数据才写）；资源稀缺本身就是供给刚性的来源——顶部持续期取决于储量/牌照/产能红线，而非价格绝对水平。命中 `is_cycle_top`/`has_pb_roe_top_mismatch` 时走顶部持续性三问（同 #3）。
- 忌：预测商品价格方向；把「价格高位」当回避理由（须先走三问）

## 6. 重资产运营型（电力、交运、机场、港口、高速）

- 主方法：**PB + 分红 / FCF 收益率**
- 买方提示：稳定现金流/分红 vs 增长稀薄；股息利差作绝对锚
- 忌：用高 ROE 标准苛责

## 红利溢价透镜（跨 archetype 叠加）

- 触发：`dividend_yield` 显著 + `payout` 高 + `is_harvest_candidate` label
- 买方提示：增长油门放缓，兑现看分红/FCF，**不由此直接定收租终局**（禁类债）

## 价值陷阱风险

- `goodwill_ratio`（商誉/总资产，>15% 减值风险）、`ppe_ratio`（>40% 折旧敏感）
- 买方提示：高 ROE 是否被商誉/固定资产撑起（有数据才写）

使用：匹配模式后判断倍数是否匹配持续能力；阈值仅直觉锚，不是硬切。裁决用四枚举整词。
