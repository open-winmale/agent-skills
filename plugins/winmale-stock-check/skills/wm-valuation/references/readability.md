# 可读性 SSOT

总原则：**专业、买方视角、准确、简洁、易懂**（详见 `output-skeleton.md`）。

## 头区（散文）

- 标题行：`**{name}** {symbol} · {l1} · {l3}`
- `> **商业模式：**` / `> **30秒读懂：**`；核心观点 3 条
- 30 秒必含裁决四枚举整词之一 + `截至 {as_of}`

## 术语首次释义（正文内括号，≤12 字）

- 括号里必须是**生活类比或日常动作**，不能是公式或更难的行话。
- 正例：「盈利收益率（每投 100 元一年赚回的净利润）」；反例：「净现比（经营现金流÷净利润）」——这是公式不是白话。
- **结论段就地重译**：核心观点/30秒/定价含义等高扫读段，关键术语即使前文已释义也须就地白话。

## 禁止出现在用户正文

- **内部字段名**：`pe_daily`/`roe_avgipo`/`shiller_*`/`fcf_yield`/`ev_*`/`peg_*`/`pct5y` 等 JSON key → 写业务词（如「市盈率 25 倍」），不写字段名
- **股票代码前缀 period**（`600519:2026:Q1`）→ 写「截至 2026年Q1」
- **英文枚举标签**：high_margin_low_turn / net_interest_income
- **模糊时间词**：最新/当前/最近一期/目前 → 用 period/as_of 具体值
- **外部数据源名称**：Wind/万得/同花顺/Bloomberg 等
- **模板标记照抄**：「强制句式」「必须输出——」等指令标记

## 表与散文

- **估值小表**（主）：`指标 | 数值 | 五年分位`；有 PE/PB + 分位即出
- **行业对照表**（辅）：仅本章 ≥2 行双侧同口径时出 `与行业对照`，表头 `指标 | 本公司 | 行业`
- **估值小表零表**：凑不齐行（如亏损期只剩 PB、缺分位）→ 该章零表，数字写散文。**无表优于碎表**
- **无对照 → 该章零对照表**；数字进估值小表或散文
- **不要**「本公司指标」表；**不要**用 `—` 凑列；**不要**旧表头「对照/分位」
- **现金流类型不入表**；解读段用类型短名即可
- 表内只有数字；解读在表后（或整章散文）
- 禁内部字段名与 period 地址；禁无依据 `≈`
